## Reproduction steps

Running the following command with install, prebuild, and run android

```
pnpm run show-bug
```

Once you're in the app, navigate to the search tab, and click on on the link to Shawn's profile.

From there, follow the steps in [app/(tabs)/search/shawn.android.tsx](<https://github.com/bentsignal/expo-ui-jetpack-button-repro/blob/main/app/(tabs)/search/shawn.android.tsx>). There is a comment above the bugged line telling you how to change it to reproduce the bug.
